Algorithm:

2. Select the color with the minimum count (the rarest).
3. Scan the grid to collect all row indices and column indices where this color appears.
4. Find the minimum and maximum row index and column index among those occurrences. This defines the bounding rectangle.
5. Compute the rectangle’s height and width from those min/max indices.
6. Create a new grid of that height and width, filling every cell with the rarest color.
7. Return this filled rectangle.
