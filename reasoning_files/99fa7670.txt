Here’s how I would solve it from the given I/O pairs and patterns I observe:

1) Identify the pattern from examples
- Non-zero cells are “emitters.”
- For an emitter at (r, c) with value v:
  - Fill its entire row to the right from column c to the last column with v.
  - Also fill the last column from row r down to the bottom with v.
- If multiple emitters influence the same output cell, the one that comes later in row-major order (top-to-bottom, left-to-right) overwrites earlier writes. This is evident where a lower emitter overwrites values in the last column below it.

2) Validate the pattern with the given examples
- Example 1: 2 at (1,2) paints row 1 from col 2 rightward as 2 and the last column from row 1 downward as 2. Then 3 at (3,1) paints row 3 from col 1 rightward as 3 and overwrites the last column from row 3 downward with 3. Matches the output.
- Example 2: 6 at center (1,1) paints row 1 from col 1 to end and last column from row 1 to bottom. Matches.
- Example 3: Same behavior with two emitters; the later one in row-major order overwrites the last column beneath it.
- Example 4: Multiple emitters on different rows; each paints rightward on its row and downward in the last column from its row.

3) Algorithm
- Create an output matrix of zeros with the same size as the input.
- Scan the input in row-major order and collect all non-zero cells (row, col, value).
- For each such cell in that order:
  - Fill the output’s row segment from that column to the right edge with the value.
  - Fill the output’s last column from that row to the bottom with the value.
- Return the output.

4) Why this ordering matters
- Processing in row-major order ensures that lower emitters overwrite the last column below them, matching the examples.
- We don’t protect existing values; later writes overwrite earlier ones in overlaps, which is required.

5) Structure
- Helper to allocate a zero-initialized output matrix of the same dimensions.
- Helper to extract all non-zero positions in row-major order.
- Helper to “spread” a value from (r, c): write across the row to the right, and down the last column.
- Main function ties this together: build output, gather emitters, apply the spread for each, and return.
