Here’s how I would solve it based on the I/O examples:

1) Understand the grid layout
- Each input is a 3×11 grid.
- Columns 1–3 contain a 3×3 block of meaningful data.
- Columns 4 and 8 are constant separators (always 5 in the examples).
- Columns 5–7 and 9–11 start as zeros in the input but get filled in the output.
- The left 3×3 (cols 1–3) is preserved unchanged in the output.

2) Spot the transformation pattern
- Columns 5–7 in the output are the 3×3 from columns 1–3 rotated 90 degrees clockwise.
- Columns 9–11 in the output are the 3×3 from columns 1–3 rotated by 180 degrees.
- The separator 5’s stay as they are, and only the zero blocks get overwritten with the rotated copies.

3) Plan the algorithm
- Extract the top-left 3×3: take the first three rows and the first three columns.
- Compute two rotations of this 3×3:
  - 90-degree clockwise rotation (can be done by transposing the matrix formed by the rows in reverse order).
  - 180-degree rotation (can be done by reversing the order of rows, then reversing each row).
- Write the 90-degree rotated 3×3 into columns 5–7 of the first three rows.
- Write the 180-degree rotated 3×3 into columns 9–11 of the first three rows.
- Leave columns 4 and 8 (the 5’s) and the original 3×3 (columns 1–3) untouched.
- Return the modified grid.

4) Indexing details to match the outputs exactly
- Let the original 3×3 be A[i][j] for i,j in 0..2 (from the grid’s first 3 rows and first 3 columns).
- Place the clockwise rotation into positions grid[i][j+4].
- Place the 180-degree rotation into positions grid[i][j+8].
- Do this for i,j in 0..2.

5) Sanity check with examples
- For the first sample, rotating the 3×3 clockwise yields the middle block in the output, and rotating by 180 degrees yields the right block in the output. The same pattern holds for the other samples.

This reasoning leads directly to:
- a helper that rotates a square grid clockwise,
- a helper that performs a 180-degree rotation,
- and a routine that extracts the 3×3, produces the two rotations, and writes them into the grid at offsets +4 and +8 in columns for the first three rows.
