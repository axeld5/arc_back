Here’s how I’d solve it from the I/O examples.

1) Core pattern from the examples
- Each puzzle contains a single 2x2 block of identical, non-zero numbers (in all the examples it’s 3). That block never changes in the output.
- The only cells that get filled in the output lie along the two rows and the two columns that define that 2x2 block (i.e., the block’s top and bottom rows, and its left and right columns).
- Non-zero numbers that are aligned with those two rows or those two columns “stretch” toward the 2x2 block, filling all cells between the number and the block, stopping just before entering the 2x2 block.
- Numbers not on those specific rows/columns stay unchanged.

2) Plan to reconstruct the transformation
- Step A: Find the anchor block
  - Scan the grid top-left to bottom-right to find the first 2x2 area where all four entries are equal and non-zero.
  - Record the top-left coordinate (r, c) and the value v of that 2x2 block.
  - The anchor rows are r and r+1, and the anchor columns are c and c+1.

- Step B: Propagate other values toward the block
  - Iterate all cells (i, j). If the cell is zero or equals v (the block’s value), ignore it.
  - Horizontal propagation (same row as the block):
    - If i equals r or r+1 (on one of the anchor rows):
      - If j < c (the value is to the left of the block), fill every cell (i, k) for k = j+1 up to c-1 with this value.
      - If j > c+1 (the value is to the right of the block), fill every cell (i, k) for k = j-1 down to c+1 with this value.
      - This paints a horizontal stripe from the value to the nearest vertical edge of the block, stopping just before the block.
  - Vertical propagation (same column as the block):
    - If j equals c or c+1 (on one of the anchor columns):
      - If i < r (the value is above the block), fill every cell (k, j) for k = i+1 up to r-1 with this value.
      - If i > r+1 (the value is below the block), fill every cell (k, j) for k = i-1 down to r+1 with this value.
      - This paints a vertical stripe from the value to the nearest horizontal edge of the block, stopping just before the block.

- Step C: Return the modified grid.

3) Why this matches the examples
- Example 1: The 2x2 block of 3s is at rows 3–4 and cols 2–3. The 1 at row 3, col 8 lies on an anchor row, so it fills left toward the block across row 3, stopping at col 4. The 6 at col 2 below the block lies on an anchor column, so it fills upward to just below the block. Nothing else moves because they’re not aligned with the anchor rows/columns.
- Example 2: The 3 block is at rows 2–3, cols 5–6. Row 2 has a 7 left of the block and an 8 right of it; both stretch toward the block along row 2. Column 6 has an 8 above that stretches down to just above the block; column 5 has a 7 below that stretches up to just below the block. All other items not on those axes stay put.
- Example 3: The 3 block is at rows 6–7, cols 4–5. A 1 at column 4 above the block stretches down that column to just above the block; nothing else aligns with the two anchor rows or columns, so the rest remains unchanged.

4) Implementation notes
- First pass: detect the first 2x2 same non-zero block by scanning all top-left candidates and checking the 2x2.
- Second pass: for every non-zero cell not equal to the block’s value, check whether it lies on an anchor row or column and fill inclusively between that cell and the nearest edge of the 2x2 block, stopping just before the block.
- Avoid touching the 2x2 itself. Ignore zeros as sources.
