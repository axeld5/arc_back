- Observe the invariants:
  - The first column is preserved exactly as in the input.
  - The last row is the same as the input in column 0, and all other columns in the last row are set to 4.
  - There is a line of 2s running along the anti-diagonal (top-right to bottom-left), but it excludes the first column and the last row. In coordinates, these 2s sit at positions where row + col = last_row_index and col ≥ 1.

- Turn that into concrete steps:
  1) Let H be the number of rows and W the number of columns; last_row_index = H - 1.
  2) For every column c from 1 to W - 1, set the cell in the last row at (last_row_index, c) to 4. Do not touch column 0.

- Notes:
  - This matches all provided examples: the constant in the first column remains, a row of 4s fills the bottom (except the first cell), and a single 2 appears in each of the rows above along the anti-diagonal.
