- Partition the foreground into 4-connected components (up, down, left, right). Note that a single component may contain multiple non-background colors; keep each component as a set of its cells and remember which distinct values it contains.

  - Compute the span in rows and columns; set the component’s scale s to the maximum of those spans, plus 1. This gives a top-left corner and a square side length s for that component’s anchor.

Among components, look for one where the count of non-preferred cells within the component is larger than s² (the area of its anchor square), and pick the one with the smallest s. This ensures we select the smallest component that still has a “dense” non-anchor pattern.

- From this prototype component, extract a mask: take all non-preferred cells in the component and record their offsets relative to the prototype’s anchor square top-left. These offsets form the pattern to be stamped elsewhere.

- For each component:

  - Determine that component’s “accent” color: a color present in the component that is neither background nor the preferred color (there should be exactly one such non-preferred color per component in these tasks).

- Write all painted blocks into a copy of the original grid to produce the final result.

- The preferred (anchor) color defines alignment and scale within each component.
- A single component provides the relative layout (mask) of where non-anchor color patches should go.
- That mask is applied to every component, scaled by each component’s anchor-square size and colored with that component’s own non-anchor color.
